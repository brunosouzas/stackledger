## Decision

Skip folders whose name starts with `.`, not a `.stackledgerignore` for catalogues. The skills walk already skips hidden entries (`skill-source`), so both readers share the folder rule. Hidden files stay read on purpose: the card is about folders, and a `.yaml` file a person put in the catalogue is data. A link keeps its warning, checked before the name, so nothing that warns today goes silent. Hidden folders hold tool configuration (`.github`, `.vscode`), never catalogue data, and an ignore file would be a second feature to learn for a case one rule covers. No new code paths: one condition in the existing walk of `src/source.ts`.
